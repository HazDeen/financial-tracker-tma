# Мои финансы 1.3.0

Подписанный APK: `moi-finansy-1.3.0.apk`, versionCode 4, Android 8.0+ (API 26).

## Изменения

- Восстановление пароля по логину и одноразовому резервному коду. При регистрации и после восстановления выдаётся новый код; существующий пользователь может создать код в профиле с подтверждением текущего пароля. Предыдущий код заменяется, после восстановления прежние сеансы входа отзываются.
- Выбор месяца, дня или произвольного диапазона в сводке и истории. Обе границы включены: например, 23.09.2026–23.10.2026. Стрелки переключают соседние интервалы для сравнения.
- Включены текущие доработки интерфейса, начального остатка, расписания и профиля.

## Установка

APK подключается к `https://finance.hazdeen.xyz`. Сначала обновите backend и примените миграции, затем устанавливайте APK поверх предыдущей версии. Ключ подписи остаётся прежним. Без обновления backend новые функции не будут работать.

В `site-update-1.3.0.zip` находятся серверные файлы, миграции, исходники интерфейса и готовая веб-сборка; `frontend-1.3.0.zip` содержит только веб-сборку. Сохраните резервную копию сервера и базы, распакуйте полное обновление в корень проекта, сохранив существующие `.env`. Для PostgreSQL выполните `alembic upgrade head` из `backend`: последняя миграция `d492a328b032` создаёт таблицу резервных кодов. Для SQLite таблица создаётся при запуске. Перезапустите сервер приложения и обновите статику.

Секреты, базы и ключ подписи не включаются в архивы и коммит. Требуется интернет и Android System WebView/Chrome 111+.

## Проверки

28 серверных тестов; проверки границ и переходов периодов и расчёта расписания; сборка TypeScript/Vite; проверка подписи APK и метаданных Android SDK. Запуск на физическом Android-устройстве не проверен. Сервер автоматически не обновляется.
