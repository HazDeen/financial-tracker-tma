# Мои финансы для Android

Готовый файл: `../output/android/moi-finansy-1.3.0.apk`.

## Установка

1. Передайте только APK на телефон (например, через Telegram или USB).
2. Откройте файл и разрешите установку из этого источника, если Android попросит.
3. Запустите «Мои финансы». Войдите в существующий аккаунт сайта или создайте новый.

Требования: Android 8.0 (API 26) и новее, интернет, Android System WebView/Chrome версии 111 или новее. Приложение проверяет версию WebView и предлагает обновление через Google Play. На старых телефонах обновление WebView может понадобиться до первого запуска.

Сервер: https://finance.hazdeen.xyz. Учётные записи и данные общие с сайтом. Интерфейс включён в APK и обновляется установкой следующей версии. Офлайн-ввод и синхронизация не реализованы. Приложение запрашивает только доступ к интернету; выбор выписки выполняет системное окно Android, без широкого доступа к файлам.

## Архитектура

Нативная Activity на Java, системный WebView, React/Vite из `frontend`. Локальные ресурсы перехватываются только на `https://finance.hazdeen.xyz/__android__/`, запросы `/api/v1` идут на настоящий сервер. Так интерфейс и API сохраняют один HTTPS origin, а существующие HttpOnly/SameSite cookie работают без изменения серверной авторизации. Внешние HTTPS-ссылки открываются в браузере. Проверка TLS остаётся системной, HTTP и смешанный контент запрещены. Резервное копирование данных приложения отключено.

Кнопка «Назад» закрывает модальное окно, затем возвращает на главную, затем сворачивает приложение. Сессия сохраняется между запусками; сервер ограничивает срок сессии.

## Повторная сборка на macOS

Нужны Node/npm, JDK 21 и Android SDK с `platforms;android-35` и `build-tools;35.0.0`.

Из корня проекта:

```sh
npm ci --prefix frontend
./scripts/build-android.sh
```

Скрипт создаёт подписанный release APK напрямую официальными инструментами Android SDK (`aapt`, `javac`, `d8`, `zipalign`, `apksigner`). Нативных библиотек и ограничений на архитектуру процессора нет. Android Studio/Gradle проект также включён для дальнейшей разработки.

Ключ подписи и пароль хранятся **вне репозитория** в `~/.local/share/hazdeen-finance-signing/`. Сохраните эту папку в защищённой резервной копии: для установки обновлений поверх текущего приложения необходим тот же ключ. Не пересылайте её вместе с APK. Пути можно переопределить через `FINANCE_JAVA_HOME`, `ANDROID_HOME`, `FINANCE_SIGN_DIR`.

**Версия 1.3.0 требует обновления серверных API и миграций до `d492a328b032` перед установкой.** Подробности — в `RELEASE-1.3.0.md`. Для локального просмотра запустите `../start.sh` и откройте http://127.0.0.1:8000.

Перед следующей публикацией увеличьте versionCode/versionName в `android/app/build.gradle` и параметрах сборки в `scripts/build-android.sh`.

## Проверки

- Успешная сборка TypeScript/Vite.
- 28 тестов сервера: аккаунты, изоляция данных, операции, CSV/PDF.
- Проверка мобильной и настольной вёрстки в Chrome; снимки с демонстрационными данными находятся в `output/android`.
- Проверка подписи APK v2/v3, минимальной версии Android и наличия ресурсов внутри APK.
- Android lintRelease: успешно, без ошибок; предупреждения касаются JavaScript в WebView и targetSdk 34.
- Браузерный сценарий на отдельной локальной базе: регистрация, создание расхода, сохранение после перезагрузки, предварительный просмотр CSV.
- Запуск APK на Android-устройстве или эмуляторе в этой сессии не выполнен.

Проверка на физическом телефоне родственника необходима после установки: войти, добавить небольшую тестовую запись, открыть выписку из системного выбора файлов и повторно открыть приложение. Демонстрационные суммы на снимках не являются данными реального аккаунта.
