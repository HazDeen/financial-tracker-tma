# Мои финансы 1.5.0

APK: `moi-finansy-1.5.0.apk`, versionCode 6, Android 8.0+. Интерфейс включён в APK. Для установки поверх 1.4.0 используется тот же ключ подписи; удалять приложение не требуется.

## Что изменилось

- Компании: автозаполнение финансовых показателей из текстового PDF или CSV, выбор колонки периода, пересчёт коэффициентов и сохранение отчёта. Для сканов без текстового слоя требуется другой файл; OCR не выполняется. XLSX сохраняется с ручным вводом показателей.
- Мои вклады: сохранение суммы, ставки, срока и даты открытия. Ежемесячные проценты без капитализации учитываются в доходах и балансе при обращении к серверу; наступившие выплаты добавляются один раз, будущие выплаты показываются отдельно. Расчёт до налога: сумма × ставка ÷ 12.
- Советы: карточки по выбранному периоду и диалог с финансовым помощником. Базовый разбор работает без ключа Gemini.
- Системный выбор файлов Android допускает PDF, CSV и XLSX.

## Обновление сервера и установка

Сначала обновите сервер, затем устанавливайте APK. Требуются API импорта компаний, вкладов и диалога, а также миграции до `f614c540d254` включительно. Сохраните обычную резервную копию рабочей базы перед обновлением.

1. Загрузите APK по SFTP в `/home/hazdeen/moi-finansy-1.5.0.apk`.
2. На сервере выполните:

```sh
cd /var/www/smart-finance
git pull --ff-only
bash scripts/update-server.sh /home/hazdeen/moi-finansy-1.5.0.apk
```

Скрипт проверяет контрольную сумму по `android/SHA256SUMS-1.5.0.txt`, применяет миграции, собирает веб-интерфейс, публикует APK, перезапускает API и проверяет сайт. Настройки базы берутся из существующего `backend/.env` или `DATABASE_URL`.

3. Скачайте и установите APK поверх прежней версии. Сессия и серверные данные сохраняются.

Ссылка после публикации: https://finance.hazdeen.xyz/moi-finansy-1.5.0.apk

Если обновляете сервер готовыми архивами, `site-update-1.5.0.zip` содержит исходники, backend, миграции, веб-сборку и скрипты релиза; `frontend-1.5.0.zip` содержит только веб-сборку. После распаковки полного архива выполните тот же `update-server.sh`, чтобы применить миграции и перезапустить API.
