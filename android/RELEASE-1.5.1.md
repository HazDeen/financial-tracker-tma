# Мои финансы 1.5.1

APK: `moi-finansy-1.5.1.apk`, versionCode 7, Android 8.0+. Интерфейс включён в APK. Для установки поверх 1.5.0 используется тот же ключ подписи; удалять приложение не требуется.

## Что изменилось

- Файлы отчётов компаний (PDF, CSV, XLSX) и банковские выписки (PDF, CSV) можно загружать размером до 100 МБ (104 857 600 байт) включительно.
- Подсказки, проверка размера и сервер используют одинаковый лимит. Для загрузки и обработки файлов клиент ожидает ответ до 5 минут.
- Собственный dropdown в выборе колонки отчёта и группы доходов НДФЛ: выбранный пункт, управление клавиатурой, адаптация к экрану.
- Сохранены вклады, импорт отчётов и финансовый советник из 1.5.0. Ограничения на число страниц PDF и операций в выписке сохраняются.

## Обновление сервера и установка

Сначала обновите сервер, затем устанавливайте APK. Требуются API импорта компаний, вкладов и диалога, а также миграции до `f614c540d254` включительно. Сохраните обычную резервную копию рабочей базы перед обновлением.

1. Загрузите APK по SFTP в `/home/hazdeen/moi-finansy-1.5.1.apk`.
2. На сервере выполните:

```sh
cd /var/www/smart-finance
git pull --ff-only
bash scripts/update-server.sh /home/hazdeen/moi-finansy-1.5.1.apk
```

Скрипт проверяет контрольную сумму по `android/SHA256SUMS-1.5.1.txt`, применяет миграции, собирает веб-интерфейс, публикует APK, перезапускает API и проверяет сайт. Настройки базы берутся из существующего `backend/.env` или `DATABASE_URL`.

3. Скачайте и установите APK поверх прежней версии. Сессия и серверные данные сохраняются.

Ссылка после публикации: https://finance.hazdeen.xyz/moi-finansy-1.5.1.apk

Если обновляете сервер готовыми архивами, `site-update-1.5.1.zip` содержит исходники, backend, миграции, веб-сборку и скрипты релиза; `frontend-1.5.1.zip` содержит только веб-сборку. После распаковки полного архива выполните тот же `update-server.sh`, чтобы применить миграции и перезапустить API.

## Проверки

Сборка TypeScript/Vite, проверка подписи APK v2/v3 и совпадения сертификата с 1.5.0, версии пакета и включённых ресурсов выполняются при подготовке релиза. На физическом Android-устройстве или эмуляторе этот релиз в данной сессии не запускался.
