# Логотип «Мои финансы»

Знак личного бюджета: белый контур с мятной линией движения денег на синем фоне. Простые линии сохраняют читаемость на маленькой иконке.

- Синий: `#006EE8`; белый: `#FFFFFF`; мятный: `#87F0CF`.
- `mark.json` — описание геометрии, исходная сетка 96×96.
- `logo.svg` — векторный оригинал; `logo-512.png` — PNG 512×512 для просмотра и экспорта.
- `python3 scripts/generate-branding.py` обновляет SVG сайта, favicon, вектор экрана запуска Android и адаптивные и монохромные Android-иконки.
- Растровые варианты: PNG 32×32 и ICO 16/32 для вкладок браузера, PNG 180×180 для закладки iPhone. Apple-иконка имеет сплошной синий фон.

Веб-интерфейс использует `BrandMark` на экранах входа, загрузки и ошибки, в навигации, мобильной шапке и блоке скачивания. Все векторные версии получаются из одного описания. В адаптивной Android-иконке знак расположен внутри безопасной центральной области, чтобы системная маска не обрезала его. Android 13+ поддерживает одноцветное тематическое оформление.
